# Pi Gym design concepts

Static, backend-free alternatives. The production `frontend/` is untouched.

From `pi-gym`:

```powershell
python -m http.server 8777 --directory design-concepts
```

Open `http://localhost:8777`, then use the top switcher to compare:

1. Calibration
2. Field card
3. Cathode

The A, B, Weight, Calendar, Edit, exercise-number, completion, and calendar controls are interactive mock behavior only.
